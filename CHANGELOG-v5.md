Zumo v5.0 — что нового

1) Быстрый контакт (кнопка в списке чатов)
   - quick-contact-server.js, public/features-v5.js
   - Люди рядом находятся по GPS. Координаты только в памяти сервера, никому не показываются.
   - Человек виден, пока открыт экран. Видят только имя и фото.
   - Выбираешь одного или несколько -> им приходит приглашение. Принял -> оба в контактах, можно писать.

2) Конструктор ботов (кнопка «Мои боты»)
   - bots-server.js, public/features-v5.js
   - Бот = аккаунт с юзернеймом на _bot. Настройки: приветствие, кнопки, правила, анкеты, ответ по умолчанию.
   - Заявки из анкет бот присылает владельцу в чат.

Новые таблицы (создаются сами): quick_invites, bots, bot_sessions. Новая колонка: messages.botButtons.
Запуск как раньше: npm install && npm start

  живая «Проверка» бота до сохранения, значок несохранённых изменений.
- Новый файл public/telegram-ui.css — оформление в стиле Telegram (только внешний вид, настройки не затронуты).

Zumo v5.2 — уровни аккаунтов
- Новое поле users.level (0…4). Старые галочки автоматически стали уровнем 1.
- Уровень ≥ 1 = галочка и прежнее правило «писать первым» только по разрешению.
- Лимит ботов зависит от уровня: 5 / 10 / 25 / 50 / 100.
- Админ меняет уровень кнопкой «Изменить уровень» в карточке пользователя (POST /api/admin/users/:username/level).
- Названия уровней и лимиты настраиваются в LEVELS (server.js).

Zumo v5.3 — дополнительные юзернеймы
- Таблицы user_aliases (алиас → аккаунт) и alias_requests (заявки). Основной юзернейм остаётся ключом аккаунта.
- Вход, профиль, поиск, личные сообщения, WebSocket и исключения ЛС принимают дополнительный юзернейм и ведут в тот же аккаунт.
- Количество на уровне: LEVELS[..].maxUsernames минус основной. На уровне 0 доп. юзернеймов нет.
- Заявка: POST /api/me/usernames/request. Выдача и отказ администрацией: /api/admin/alias-requests/:id/approve|reject. В админке — блок «Дополнительные юзернеймы» во вкладке заявок.
- Смена основного юзернейма не может забрать чужой алиас; алиасы переходят вместе с аккаунтом.
- Пользователь может удалить свой алиас: DELETE /api/me/usernames/:alias.
- Исправлено: запросы пользователей теперь читают поле level, а не только verified.

Zumo v5.4 — Bot API и BotFather
- Системный аккаунт @botfather: /newbot, /mybots, /token <бот>, /cancel. Создание бота вынесено в общую функцию createBot (веб-конструктор и BotFather).
- HTTP API по токену /bot<токен>/<метод>: getMe, sendMessage, getUpdates (long polling). Описание в BOT_API.md.
- Токен хранится только как хеш (sha256), новый токен можно выпустить в любой момент.
- Очередь входящих сообщений bot_updates (до 1000 на бота).
- Режим бота: builder или api. В api автоответы конструктора отключены. Переключается через PUT /api/bots/:username {mode}.
- Выключенный бот отвечает 403 на все методы API.
- say() теперь возвращает id сообщения.

Zumo v5.5 — интерфейс как в Telegram, уровни и юзернеймы видны всем
- Уровень аккаунта виден всем: значок у имени (уровни 1-4 с разными иконками и цветами) и строка «уровень» в любом профиле, в том числе «Уровень 0 — Обычный».
- Все юзернеймы одного аккаунта показываются в профиле (основной помечен). В своём профиле есть кнопка «запросить дополнительный юзернейм» и список заявок, ждущих решения.
- API: карточки пользователей содержат level, levelName и usernames.
- Список чатов: время последнего сообщения, счётчик непрочитанных, одна/двойная галочка («доставлено/прочитано»). /api/chats возвращает unread, lastAt, lastMine, lastRead.
- Вкладки-папки над списком: Все / Личные / Группы / Каналы / Боты со счётчиками (пустые папки скрываются).
- Нижняя панель: плавающая капсула, на «Чатах» — общий счётчик непрочитанных.
- Новый файл public/tg-clone.css (подключён последним в chat.html).

Zumo v5.6 — темы и приветственный тур
- Темы: Авто / Тёмная / AMOLED / Светлая / Океан / Сумерки (Настройки → Оформление). Файлы public/themes.css, public/themes.js.
  Тема хранится в аккаунте (settings.theme) и на устройстве. Скругление сообщений, размер текста и анимации — только на устройстве.
- pro-theme.css переведён на переменные --t-*, поэтому акцентный цвет теперь красит и его элементы.
- Приветственный тур для новых аккаунтов: public/welcome.js, public/welcome.css. Повтор — кнопка в Настройках → Оформление.
